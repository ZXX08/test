# Training Logs

Training logs are written to `logs/training/qwen3_full_sft/` by `scripts/run_full_train.ps1` or
`scripts/run_full_train.sh`.

Each full training run should keep:

- `run-<timestamp>.log`: console log with resolved training arguments, progress, loss, evaluation records, checkpoint saves, and errors if any.
- TensorBoard event files: generated when `report_to: tensorboard` is enabled.
- `trainer_state.json`: generated under `models/qwen3-4b/full/sft/` with epoch, global step, best/last checkpoint, and log history.
- `trainer_log.jsonl` and `training_loss.png`: generated by LLaMA-Factory when available.

The current repository does not include a completed training log because the training must be run on a machine with the required GPU memory and model access.
